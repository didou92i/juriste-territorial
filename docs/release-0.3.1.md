# Le droit, éclairé par les données de vos territoires

Juriste territorial guide désormais l'utilisation facultative de data.gouv.fr
pour documenter les faits : finances locales, marchés publiés et intercommunalités.

- Une méthode ciblée : producteur, millésime, périmètre, identifiants et limites.
- Un parcours d'activation sans clé PISTE, qui réutilise une connexion existante.
- Une distinction explicite entre données, règles de droit et pièces locales.
- Une recette réelle documentant recherche, métadonnées, lecture BANATIC et fichier
  absent de l'API tabulaire.
- Un guide disponible dans le ZIP du skill et les ressources du MCP juridique.

Le client coordonne les connecteurs. Les 14 outils de `droit-territorial` restent
distincts des outils data.gouv.fr. Une fiche ou deux lignes consultées ne valident
ni une base complète ni une conclusion juridique.

Validation technique : 145 tests réussis, 1 test en ligne ignoré ; style et liens
validés. Le nouveau guide a été lu via le protocole MCP stdio et retrouvé dans
le paquet distribué. Le benchmark juridique comparatif reste incomplet.
